Protección de datos y control de contactos

Reglas activas (Ley 1581 de 2012)

  • Finalidad: {{ r.finalidad }}
  • Minimización: solo datos empresariales (nombre comercial, dirección, canales publicados por el negocio). No se recopilan datos sensibles ni se deducen correos personales.
  • Procedencia: cada dato guarda fuente, URL, fecha, nivel de confianza y verificación.
  • Fuentes: Google Places API (oficial), sitios web propios respetando robots.txt, cargas manuales con fuente declarada. No se hace scraping de Instagram, Facebook ni LinkedIn.
  • Frecuencia: mínimo {{ r.dias_entre_contactos }} días entre contactos; máximo {{ r.max_intentos_sin_respuesta }} intentos sin respuesta.
  • Aprobación humana: todo mensaje se aprueba y se envía manualmente. No hay envíos masivos.
  • Retención: descartados se eliminan tras {{ r.dias_retencion_descartados }} días; prospectos nunca contactados, tras {{ r.dias_retencion_sin_contacto }} días sin actividad.
  • Derechos del titular: si alguien pide no ser contactado, usa “Agregar a lista de exclusión” en su ficha; si pide borrar sus datos, usa “Eliminar datos”.
